# Fuentes de PixelLab: componentes, recursos y lanzamiento

Los archivos listos para Unity están en `Assets/_Project/Art/`, y las composiciones en `docs/art-review/componentes-recursos-lanzamiento/`. `raw/` contiene las generaciones originales, referencias y solicitudes sin credenciales; `manifest.json` registra las rutas finales, dimensiones, hashes y jobs. Los archivos `discarded-*` son propuestas no utilizadas. El arte requiere revisión visual y posterior integración en Unity.
